Materi Pembelajaran

🅰️ Pengertian SPLDV

SPLDV (Sistem Persamaan Linear Dua Variabel) adalah dua persamaan linear yang memiliki dua variabel yang sama.

ax + by = c   dan   px + qy = r

dengan a, b, p, q ≠ 0 dan x, y adalah variabel.

🅱️ Konsep Metode Grafik

SPLDV dapat diselesaikan dengan menggambar kedua garis pada bidang kartesius. Solusi SPLDV adalah titik potong kedua garis (x, y).

Kemungkinan Solusi SPLDV:

1

Berpotongan

Memiliki 1 solusi (konsisten)

2

Sejajar

Tidak memiliki solusi (inkonsisten)

3

Berimpit

Memiliki tak hingga solusi (dependen)

🅲 Langkah-Langkah Metode Grafik

  1. Ubah kedua persamaan ke bentuk y = mx + c (eksplisit).
  2. Tentukan minimal 2 titik untuk masing-masing persamaan (gunakan tabel bantu).
  3. Gambar kedua garis pada bidang kartesius.
  4. Tentukan titik potong kedua garis.
  5. Periksa solusi dengan substitusi ke kedua persamaan.

🅳 Contoh Soal Step-by-Step

Soal:

x + y = 5 ... (1)

2x - y = 4 ... (2)

Langkah 1: Ubah ke bentuk y = mx + c

(1) → y = 5 - x   (garis biru)

(2) → y = 2x - 4   (garis oranye)

Langkah 2: Buat tabel bantu

Persamaan (1): y = 5 - x

x05
y50

Persamaan (2): y = 2x - 4

x02
y-40

Langkah 3: Gambar kedua garis pada bidang kartesius

Plot titik-titik dari tabel di atas, lalu hubungkan menjadi garis lurus. Perhatikan kedua garis berpotongan!

Grafik SPLDV: x + y = 5 dan 2x - y = 4
y = 5 - x
y = 2x - 4
Titik Potong (3, 2)

Langkah 4: Verifikasi solusi

Substitusi (3, 2) ke persamaan (1): 3 + 2 = 5 ✓

Substitusi (3, 2) ke persamaan (2): 2(3) - 2 = 4 ✓

Jadi, HP = {(3, 2)} ✅

Rangkuman

  • SPLDV adalah dua persamaan linear dengan dua variabel yang sama.
  • Metode grafik menyelesaikan SPLDV dengan menggambar kedua garis pada bidang kartesius.
  • Solusi SPLDV = titik potong kedua garis (x, y).
  • Langkah: ubah ke y = mx + c → buat tabel titik → gambar grafik → tentukan titik potong → verifikasi.
  • Tiga kemungkinan solusi: berpotongan (1 solusi), sejajar (tidak ada solusi), berimpit (tak hingga solusi).
  • Metode grafik sangat berguna untuk visualisasi masalah nyata.

📝 Pembahasan Soal 1

Langkah 1: Ubah ke bentuk y = mx + c

x + y = 4 → y = 4 - x

x - y = 2 → y = x - 2

Langkah 2: Buat tabel bantu

y = 4 - x: jika x=0 → y=4; jika x=4 → y=0

y = x - 2: jika x=0 → y=-2; jika x=2 → y=0

Langkah 3: Kedua garis berpotongan di titik (3, 1).

Langkah 4: Verifikasi

3 + 1 = 4 ✓   dan   3 - 1 = 2 ✓

Jadi, HP = {(3, 1)}

📝 Pembahasan Soal 2

Langkah 1: Ubah ke bentuk y = mx + c

2x + y = 6 → y = 6 - 2x

x - y = 3 → y = x - 3

Langkah 2: Buat tabel bantu

y = 6 - 2x: jika x=0 → y=6; jika x=3 → y=0

y = x - 3: jika x=0 → y=-3; jika x=3 → y=0

Langkah 3: Kedua garis berpotongan di titik (3, 0).

Langkah 4: Verifikasi

2(3) + 0 = 6 ✓   dan   3 - 0 = 3 ✓

Jadi, HP = {(3, 0)}

Tentukan himpunan penyelesaian SPLDV berikut dengan metode grafik:
x + 2y = 8
3x - y = 3

📝 Pembahasan Soal 3

Langkah 1: Ubah ke bentuk y = mx + c

x + 2y = 8 → y = (8 - x)/2 = 4 - ½x

3x - y = 3 → y = 3x - 3

Langkah 2: Buat tabel bantu

y = 4 - ½x: jika x=0 → y=4; jika x=8 → y=0

y = 3x - 3: jika x=0 → y=-3; jika x=1 → y=0

Langkah 3: Kedua garis berpotongan di titik (2, 3).

Langkah 4: Verifikasi

2 + 2(3) = 8 ✓   dan   3(2) - 3 = 3 ✓

Jadi, HP = {(2, 3)}

Soal 4 Sedang - Kontekstual

Harga 2 buku dan 1 pensil adalah Rp9.000. Harga 1 buku dan 2 pensil adalah Rp8.000. Tentukan harga sebuah buku dan sebuah pensil menggunakan metode grafik!
(Misal: x = harga buku, y = harga pensil, dalam ribuan rupiah)

📷 Format: JPG/PNG • Maks. 5 MB • Foto dari buku tulis

✅ Gambar berhasil diupload!

📝 Pembahasan Soal 4

Model matematika: Misal x = harga buku (ribuan), y = harga pensil (ribuan)

2x + y = 9 ... (1)

x + 2y = 8 ... (2)

Langkah 1: Ubah ke bentuk y = mx + c

(1) → y = 9 - 2x

(2) → y = (8 - x)/2 = 4 - ½x

Langkah 2: Buat tabel bantu

y = 9 - 2x: jika x=0 → y=9; jika x=4,5 → y=0

y = 4 - ½x: jika x=0 → y=4; jika x=8 → y=0

Langkah 3: Kedua garis berpotongan di sekitar titik (3⅓, 2⅓) yaitu (3,33 , 2,33).

Langkah 4: Verifikasi

2(3,33) + 2,33 = 6,66 + 2,33 = 8,99 ≈ 9 ✓

3,33 + 2(2,33) = 3,33 + 4,66 = 7,99 ≈ 8 ✓

Jadi, harga buku ≈ Rp3.333 dan harga pensil ≈ Rp2.333

💡 Catatan: Jawaban desimal dibulatkan. Bisa juga dinyatakan dalam pecahan (10/3, 7/3).

📝 Pembahasan Soal 5

Model matematika: Misal kedua bilangan adalah x dan y (x > y)

x + y = 20 ... (1)

x - y = 6 ... (2)

Langkah 1: Ubah ke bentuk y = mx + c

(1) → y = 20 - x

(2) → y = x - 6

Langkah 2: Buat tabel bantu

y = 20 - x: jika x=0 → y=20; jika x=20 → y=0

y = x - 6: jika x=0 → y=-6; jika x=6 → y=0

Langkah 3: Kedua garis berpotongan di titik (13, 7).

Langkah 4: Verifikasi

13 + 7 = 20 ✓   dan   13 - 7 = 6 ✓

Jadi, kedua bilangan tersebut adalah 13 dan 7
